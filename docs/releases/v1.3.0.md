# LumOS v1.3.0 – Gate 8: Windows 11 One-Click Installer & Auto-Setup

**Version:** 1.3.0  
**Stand:** 15. August 2026  
**Rechtlicher Status:** 100 % Kommerziell frei nutzbar (Apache-2.0 / MIT)  

## Enthalten

- **System-Preflight Check (`GET /api/v1/installer/preflight`):**
  - Prüfung der Windows 11 Kompatibilität, RAM-Kapazität (8GB+) und freiem Festplattenspeicher (5GB+).
- **Inno Setup & Silent-Installer Generator (`POST /api/v1/installer/build-manifest`):**
  - Erstellung eines fertigen Inno Setup Skripts (`tools/installer/lumos-setup.iss`).
  - Generierung eines 1-Click Silent-Setup PowerShell Skripts (`tools/installer/install-lumos-win11.ps1`) inklusive Desktop-Verknüpfung.
- **Svelte UI Erweiterung:**
  - Neue **"Windows 11 Installer & Setup Generator"**-Karte im System-Bereich mit Live-Preflight Status und Ein-Klick-Generierung.
- **49 automatisierte Backend- & API-Tests (pytest)**.
