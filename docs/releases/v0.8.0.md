# LumOS v0.8.0

## Ziel

Sichere lokale Dokumentaufnahme als Fundament für belegtes lokales RAG.

## Enthalten

- erlaubte MVP-Dateitypen für Dokumentaufnahme
- Dateiendungsprüfung
- einfache Magic-Number-/Formatprüfung
- Größenlimit für Dokumente
- SHA-256-Dokumenthash
- Duplicate-Erkennung
- strukturierte Dokumentstatus
- Ablehnung oder Quarantäne bei unsicheren Dateien
- Schutz vor Veränderung der Originaldatei
- Tests für sichere Dokumentaufnahme

## Nicht enthalten

- kein Installer
- keine Bildgenerierung
- keine E-Mail-/Kalenderfunktionen
- keine Team-/LAN-Funktionen
- keine Office-DOCX/PDF-Erzeugung
- kein Wechsel von Qwen auf `approved`
- kein automatischer Push
- kein automatischer Tag
