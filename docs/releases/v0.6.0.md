# LumOS v0.6.0

## Ziel

Sichere lokale Dokumentaufnahme als nächster Schritt nach `v0.5.2-llm`.

## Enthalten

- Validierung unterstützter MVP-Dateitypen
- einfache Magic-Number-/Formatprüfung
- Größenlimit
- SHA-256-Dokumentidentität
- Duplicate-Erkennung
- strukturierte Statusrückgaben
- Schutz vor Import unsicherer oder unbekannter Dateien
- Tests für sichere Dokumentaufnahme

## Nicht enthalten

- kein Installer
- keine Bildgenerierung
- keine E-Mail-/Kalenderfunktionen
- keine Team-/LAN-Funktionen
- kein Wechsel von Qwen auf `approved`
- kein automatischer Push
- kein automatischer Tag
