# LumOS v0.9.5

## Ziel

Gate 5 – System-, Hardware- & Modelldiagnose mit SBOM-Inventarisierung zur Vorbereitung des MVP v1.0.0.

## Enthalten

- Hardware-Diagnose API (`GET /api/v1/system/hardware`): Erfassung von OS, CPU-Kernen, Arbeitsspeicher (GB Total/Frei), GPU-Beschleunigung (CUDA/DirectML/CPU Fallback) und empfohlener Modellkonfiguration.
- GGUF-Modellscanner API (`GET /api/v1/system/models`): Prüft GGUF-Dateien im Verzeichnis `models/` und gleicht deren Status mit der Sicherheits-Allowlist (`docs/security/model-allowlist.json`) ab.
- Software Bill of Materials (SBOM) API & Datei (`GET /api/v1/system/sbom`): Generiert maschinenlesbares Lizenz- & Komponenten-Inventar unter `docs/licenses/sbom.json` (ADR-009).
- Visuelle Hardware- & Modell-Assistent Card im Svelte Floating AI Desktop.
- Interaktiver SBOM-Dialog zur Einsicht aller Lizenzen & Zwecke.
- 42 automatisierte Pytest-Tests grün, Ruff clean, Svelte-Check 0 Errors 0 Warnings.

## Nicht enthalten

- kein Wechsel von Qwen auf `approved` (bleibt `candidate`)
- kein automatischer Push
- kein automatischer Tag
