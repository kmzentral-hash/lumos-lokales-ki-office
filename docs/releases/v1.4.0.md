# LumOS v1.4.0 – Gate 9: E-Mail & Kalender-Orchestrierung

**Version:** 1.4.0  
**Stand:** 15. August 2026  
**Rechtlicher Status:** 100 % Kommerziell frei nutzbar (Apache-2.0 / MIT)  

## Enthalten

- **E-Mail Entwurfs-Generator (`POST /api/v1/mail-calendar/email/draft`):**
  - Generierung von `.eml`-Dateien zur Ablage und Vorschau.
  - Direkte Integration des `mailto:` Protokolls zum Öffnen im lokalen E-Mail-Client (Outlook, Thunderbird).
  - Quick-Button (`📧 E-Mail Entwurf (.eml)`) direkt im KI-Chat für belegte RAG-Antworten.
- **iCalendar Meeting Generator (`POST /api/v1/mail-calendar/calendar/draft`):**
  - Erzeugung von `.ics`-Kalenderdateien für Windows Kalender, Outlook und Thunderbird.
- **Svelte UI Erweiterung:**
  - Neuer Arbeitsbereich *"E-Mail & Kalender Studio"*.
- **51 automatisierte Backend- & API-Tests (pytest)**.
